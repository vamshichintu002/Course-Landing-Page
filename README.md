# StudentNest - AI-Powered Web Development Course Platform

## About StudentNest

StudentNest is an innovative online learning platform that offers a comprehensive course in AI-powered web development. Our mission is to empower aspiring developers and tech enthusiasts to build cutting-edge web applications using the latest AI technologies, without requiring extensive coding knowledge.

## Features

- **AI-Driven Curriculum**: Learn to leverage AI tools for full-stack web development.
- **Interactive Learning**: Engage with live sessions, video tutorials, and hands-on assignments.
- **Tailored Tracks**: Customized learning paths for aspiring developers and tech enthusiasts.
- **Project-Based Learning**: Build real-world projects to create an impressive portfolio.
- **Industry-Relevant Skills**: Master in-demand technologies like Generative AI, v0, Supabase, and more.
- **Responsive Design**: Fully responsive web application for seamless learning on any device.

## Tech Stack

- **Frontend**: Next.js, React, TypeScript
- **Styling**: Tailwind CSS, CSS Modules
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Font**: Custom Geist font (Sans and Mono variants)

## Getting Started

To run this project locally:

1. Clone the repository:
   ```
   git clone https://github.com/your-username/StudentNest.git
   cd StudentNest
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Run the development server:
   ```
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

## Project Structure

- `app/`: Next.js app directory containing pages and layouts
- `components/`: Reusable React components
- `public/`: Static assets like images and fonts
- `styles/`: Global styles and CSS modules
- `lib/`: Utility functions and shared logic

## Key Components

- `LandingPageComponent`: Main landing page with course overview and features
- `CurriculumSectionComponent`: Detailed course curriculum and module breakdown
- `TailoredTracks`: Highlights of what learners will achieve
- `WhoIsThisFor`: Target audience information
- `TechStackCarousel`: Showcase of technologies covered in the course
- `AnimatedAdoptionLifecycleChart`: Visual representation of AI adoption lifecycle

## Customization

You can easily customize the content, styling, and features of the platform by modifying the respective components and CSS files.
